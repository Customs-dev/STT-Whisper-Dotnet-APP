# Prompto

Prompto is a Windows tray app (WinForms, .NET 9) for speech-to-text transcription using Whisper.

## Features

- global hotkey recording
- Whisper transcription (Vulkan with CPU fallback)
- text insertion at current cursor location (Notepad, Chrome, Outlook, other Win32 editors)
- transcribed text is automatically copied to the clipboard — you can paste it again anytime with Ctrl+V
- optional WebSocket server for live segment streaming
- optional chunked transcription mode (live stream)

## Requirements

- Windows 10/11 x64
- .NET 9 SDK (for development)
- Whisper model `.bin` file (not bundled with repository or installer)

Recommended model:

- `ggml-large-v3.bin`
- `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin`

Runtime model location:

- `%APPDATA%\Prompto\models\ggml-large-v3.bin`

## Run (dev)

```powershell
dotnet run --project "src\SttApp\SttApp.csproj"
```

## Build

```powershell
dotnet build "src\SttApp\SttApp.csproj" -c Release
```

## Installer

Files:

- `installer/Prompto.iss`
- `build-installer.ps1`

Build installer:

```powershell
.\build-installer.ps1
```

Output:

- `installer\Output\PromptoSetup.exe`

## Configuration

User settings file:

- `%APPDATA%\Prompto\settings.json`

Important keys:

- `EnableWebSocket` - enable/disable WS server
- `WebSocketPort` - WS server port (default 5050)
- `ChunkIntervalSeconds` - chunk interval; active only when WebSocket is enabled

## WebSocket Stream

When enabled, segments are streamed to:

- `ws://localhost:5050/stt/` (or selected port)

Note: some websites block `localhost` via CSP `connect-src`. For testing, use a local HTML page (for example `ws-test.html`).

## Project Structure

- `Program.cs` - entry point
- `TrayApp.cs` - hotkey pipeline, chunking, paste logic, WS integration
- `WhisperTranscriber.cs` - Whisper initialization and transcription
- `AudioRecorder.cs` - audio capture
- `TextInjector.cs` - text insertion into target applications
- `WebSocketServer.cs` - local WS server
- `SettingsForm.cs` - settings UI
- `AboutForm.cs` - about dialog

## Troubleshooting

### Native Library not found - Whisper Library

Use the latest installer generated by `build-installer.ps1` (multi-file publish including `runtimes\...\whisper.dll`).

### Bitmap image is not valid (installer)

Make sure Inno Setup does not use `.ico` as `WizardSmallImageFile`.

### WebSocket blocked in browser

If browser console reports CSP `connect-src` blocking, this is a website policy issue, not a Prompto server issue.
